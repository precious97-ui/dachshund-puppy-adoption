# Little Sausage Haven

Premium Dachshund puppy adoption website.

A clean, modern, and elegant static site designed for showcasing available Dachshund puppies and handling adoption inquiries.

## Live Site

Once connected to Netlify, your site will be available at a free `.netlify.app` subdomain. You can later add a custom domain.

## Features

- Beautiful hero section
- Available puppies grid with status badges
- About & Why Us sections
- Customer testimonials
- Netlify Forms ready contact/adoption form
- Fully responsive (mobile-first)
- Premium warm color palette & elegant typography

## Tech Stack

- Pure HTML, CSS & JavaScript (no frameworks)
- Google Fonts (Playfair Display + Inter)
- Ready for free hosting on **Netlify**

## How to Deploy on Netlify (Free)

1. Go to [https://app.netlify.com](https://app.netlify.com) and log in (or sign up with GitHub).
2. Click **Add new site** → **Import an existing project**.
3. Choose **GitHub** and authorize if needed.
4. Select the repository: `precious97-ui/dachshund-puppy-adoption`.
5. Leave build settings empty (this is a pure static site).
6. Click **Deploy site**.

That’s it! Netlify will give you a free URL like `https://random-name-123.netlify.app`.

### Enable the Contact Form

The contact form is already set up with Netlify Forms. After the first deploy:

1. Go to your site in Netlify → **Forms**
2. You will see the form submissions appear there.

### Adding a Custom Domain Later

1. In Netlify → Domain settings → Add custom domain
2. Follow the instructions to point your domain (or buy one through Netlify).

## Local Development

Just open `index.html` in your browser, or use any local server:

```bash
npx serve .
```
